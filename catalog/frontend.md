# Frontend catalog

Starter set, biased toward the house stack (Next.js, GSAP). Extend freely.

## Frameworks / meta-frameworks

| Tool | Use it for | Link |
| --- | --- | --- |
| Next.js | React meta-framework, SSR/SSG/RSC. House default. | https://nextjs.org |
| Astro | Content sites, islands, minimal JS. | https://astro.build |
| SvelteKit | Small, fast apps; less boilerplate than React. | https://kit.svelte.dev |
| Vite | Build tool / dev server for SPAs. | https://vitejs.dev |
| Remix | Web-standards routing + data loading (now merging into React Router). | https://remix.run |

## Styling

| Tool | Use it for | Link |
| --- | --- | --- |
| Tailwind CSS | Utility-first styling. Pairs with most component kits below. | https://tailwindcss.com |
| CSS Modules | Scoped CSS with zero runtime. | https://github.com/css-modules/css-modules |
| Panda CSS | Type-safe styling, zero-runtime. | https://panda-css.com |
| vanilla-extract | CSS-in-TS, compiled away. | https://vanilla-extract.style |

## Animation

| Tool | Use it for | Link |
| --- | --- | --- |
| GSAP | Timeline animation, scroll effects. House default. | https://gsap.com |
| Motion (Framer Motion) | Declarative React animation. | https://motion.dev |
| Lenis | Smooth scroll, pairs with GSAP ScrollTrigger. | https://lenis.darkroom.engineering |
| Lottie | Play After Effects / JSON animations. | https://lottiefiles.com |
