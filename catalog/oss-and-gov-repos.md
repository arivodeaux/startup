# Open-source & government repos / open data

Public code and open datasets from governments and public institutions. Most are
free to use; check each one's license and attribution terms.

## NASA

| Resource | What | Link |
| --- | --- | --- |
| NASA Open APIs | APOD, Mars rover photos, NEO asteroids, EPIC, more. One key covers all. | https://api.nasa.gov |
| code.nasa.gov | NASA's open-source software catalog (thousands of projects). | https://code.nasa.gov |
| NASA on GitHub | Org with hundreds of repos. | https://github.com/nasa |
| NASA Open Data Portal | Datasets across missions. | https://data.nasa.gov |

| Resource | What | Link |
| --- | --- | --- |

| GSA / 18F on GitHub | US gov digital services, open source. | https://github.com/GSA |
